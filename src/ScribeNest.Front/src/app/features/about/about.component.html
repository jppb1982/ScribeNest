Acerca de ScribeNest

ScribeNest es una plataforma de contenido técnico para developers. El objetivo no es competir con un CMS real, sino mostrar una aplicación full stack moderna, ordenada y defendible en entrevistas técnicas.

Stack principal

  • Backend: .NET 8, ASP.NET Core API/MVC, Entity Framework Core y SQLite.
  • Frontend: Angular 16 standalone components, Bootstrap 5 y consumo de API REST.
  • Arquitectura: separación por capas con Domain, Application, Infrastructure y Web.
  • Patrones: Repository + Unit of Work en la parte MVC y persistencia con EF Core.

Qué demuestra

  • Diseño de una API REST con DTOs, paginación, búsqueda y filtro por categoría.
  • Frontend Angular desacoplado, con rutas, servicios HTTP, estados de carga y manejo básico de errores.
  • Persistencia local simple con seed técnico para poder clonar y probar el proyecto rápido.
  • Una feature de IA mock/local preparada para evolucionar a una integración real sin depender de una API paga.

Alcance consciente

El proyecto prioriza claridad, mantenimiento y aprendizaje. Por eso evita crecer hacia una solución enterprise innecesaria. La idea es que pueda estudiarse completo y que cada decisión técnica pueda explicarse con criterio.
